
# PROGRAM KASIR SEDERHANA

## Deskripsi
Program kasir sederhana dibuat menggunakan bahasa Kotlin dengan konsep OOP.

## Konsep yang Digunakan

### 1. Class
Class Kasir digunakan sebagai cetak biru objek transaksi.

### 2. Public
Variabel namaBarang dan harga dapat diakses dari luar class.

### 3. Private
Variabel jumlah hanya dapat diakses dari dalam class.

### 4. Function
- ubahJumlah() untuk mengubah jumlah barang.
- hitungTotal() untuk menghitung total pembayaran.

## Hasil Output
Nama Barang: Pensil
Harga: Rp3000
Jumlah: 5
Total Bayar: Rp15000

## Kesimpulan
Program ini menerapkan konsep OOP Kotlin dengan menggunakan class, object, function, public, dan private.
